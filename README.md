# Desktop Control releases

Windows installer for **Desktop Control**, which lets Claude Desktop or Codex see your screen and work in Windows programs (Excel, Tally, browsers and more). No source code lives here.

## Install
1. Download `DesktopControl-Setup.zip` from the [latest release](../../releases/latest).
2. Right-click the zip > **Extract All...**
3. Double-click **Setup.bat** (not as administrator) and choose Claude Desktop, Codex or both.
4. Fully quit and reopen the app.

To stop Claude at any time, press **F12**. Full instructions are in `README.txt` inside the zip.
